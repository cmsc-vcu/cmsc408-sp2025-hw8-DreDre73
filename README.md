# cmsc408-sp2025-hw8

## Homework 8 — World Bank Indicator Analysis

This assignment focused on querying and analyzing real-world country and development data from the World Bank using SQL.

## What I Did
- Explored the structure of three datasets: `wdi_country`, `wdi_data`, and `wdi_series`
- Used `SELECT`, `WHERE`, `GROUP BY`, `ORDER BY`, `JOIN`, and `CTE` to query and summarize data
- Identified non-country entities and filtered them out
- Created pivot-style tables and calculated percentages by region and income group
- Investigated missing data (e.g., Venezuela) and corrected it
- Handled complex queries involving cross joins, missing combinations, and percentage calculations

## Skills Practiced
- SQL aggregation and filtering
- Data cleaning and transformation
- Subqueries and common table expressions (CTEs)
- Handling NULL values and formatting results for analysis

This assignment gave me hands-on experience with data analysis in SQL
